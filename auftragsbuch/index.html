Rollen

Rollen stehen fest im Tool (Code). Sie steuern nur, welche Knöpfe man sieht – wer auf die Excel-Freigabe zugreifen darf, regelt weiterhin SharePoint.

Einrichtungslink für andere Geräte

Diana oder Nico öffnen diesen Link einmal – danach ist auf dem Gerät dieselbe Datei verknüpft. Der Link enthält nur Datei-IDs, keine Daten.

Schreibweisen der Auftraggeber

Gruppen, die vermutlich derselbe Kunde sind (aktuelles Jahr + Vorjahr). Das Formular schlägt künftig automatisch die häufigste Schreibweise vor.
