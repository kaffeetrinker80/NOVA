## GitHub Actions

### Keep Supabase Alive
Läuft täglich um 12:00 Uhr (München) und sendet einen Ping an Supabase,
damit das Projekt nicht nach 7 Tagen Inaktivität pausiert wird.

**Secret das benötigt wird:**
- `SUPABASE_ANON_KEY` → im GitHub Repo unter Settings → Secrets
